# گزارش بررسی نسخهٔ آمادهٔ انتشار

- `npm run check`: موفق؛ ساختار ۱۰ آزمایش و ۲۰ پرسش، حذف سؤال راکت و توپ، نحو JavaScript، هماهنگی Shared.gs با کد مرورگر و وجود فایل‌های محلی بررسی شد.
- `npm test`: ۱۹ آزمون موفق؛ تحلیل تمام ترکیب‌های پاسخ، چرخه‌ها، اعتبارسنجی، آمار، حداقل جمعیت، ثبت تکراری، قفل/زمان فعالیت، تزریق فرمول شیت و کنترل مبدأ پیام‌ها بررسی شدند.
- ۱۲۰ ثبت کامل و یکتا در **شبیه‌ساز شیت و کش** ذخیره و شمرده شدند؛ این آزمون بار واقعی گوگل نیست.
- در Chrome، مسیر واقعی فرم شروع → ۲۰ پرسش → مرور → پایان → ۱۰ کارت گزارش اجرا شد.
- جلوگیری از شروع با فرم خالی، جلوگیری از ادامه با پاسخ خالی، ورود اعداد فارسی و ماندن پاسخ پس از رفرش بررسی شدند.
- گزارش ذخیره‌شده پس از بارگذاری دوباره در دسترس بود و خطایی در کنسول ثبت نشد.
- صفحهٔ پرسش و گزارش در عرض ۳۹۰ پیکسل و صفحهٔ اصلی در عرض ۳۶۰ پیکسل، اسکرول افقی ناخواسته نداشتند.
- خروجی استاتیک با `npm run package` آماده می‌شود؛ runtime سایت هیچ وابستگی npm ندارد.

## بررسی‌های باقی‌مانده پس از اتصال حساب‌ها

۱. تأیید ذخیرهٔ واقعی از GitHub Pages در Apps Script و Google Sheet.

۲. عملکرد پل iframe روی مرورگرها و شبکه‌های واقعی دانشجویان.

۳. آزمون ارسال هم‌زمان با حساب مالک و بررسی سهمیهٔ واقعی.

۴. موفقیت اجرای workflow و نشانی عمومی Pages.

در نسخهٔ تحویل‌شده، endpoint خالی است؛ سایت به‌وضوح در حالت آزمایشی اجرا می‌شود. هیچ آمار ساختگی به‌عنوان آمار کلاس نمایش داده نمی‌شود.
